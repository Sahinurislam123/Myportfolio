# Sahinur Islam — 3D Cinematic Portfolio

## Upload to GitHub
Upload ALL files in this ZIP directly into the repository root (the same level as `index.html`).
Do not put the photos into an `images` folder. This version expects photos in the root.

Files:
- index.html
- style.css
- script.js
- profile.jpg
- photo-1.jpg through photo-6.jpg

The portfolio includes a 3D animated photo carousel, swipe support, About, Gallery, and Contact sections.
The carousel slots use your uploaded photos; a few are repeated until you add more unique pictures.
